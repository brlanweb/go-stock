# 首页严格三列总览实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将首页改为严格三列分区，按指定顺序展示账户、情绪、持仓、有效高分推荐、热点、历史走势与复盘信息，并将持仓和推荐列表限制为最多 5 条。

**架构：** 保留现有首页并行数据请求和接口，仅重组 `Home.vue` 的派生数据、模板与响应式网格。使用 Node 内置测试运行器读取 Vue 单文件组件，建立布局顺序和数量限制的结构契约，不引入新的前端测试框架。

**技术栈：** Vue 3、TypeScript、Vite、Node.js 22 内置测试运行器、Go 发布脚本。

---

## 文件结构

- 创建：`web/test/home-layout.test.mjs`，验证首页板块顺序、全宽区域和最多 5 条约束。
- 修改：`web/package.json`，增加基于 `node --test` 的测试脚本。
- 修改：`web/src/views/Home.vue`，实现严格三列首页、有效推荐排序与对齐样式。

### 任务 2：首页数据筛选与严格布局

**文件：**
- 修改：`web/src/views/Home.vue`
- 测试：`web/test/home-layout.test.mjs`

- [ ] **步骤 1：收敛派生数据**

将 `actionRows` 改为有效状态最多 5 条。新增 `recommendedRows`：过滤 `pending_entry` 与 `holding` 中已有可计算 `change_pct` 的记录，按收益率从高到低排序并截取前 5 条；尚无建仓价的等待建仓记录只保留在持仓信息中。这与用户确认的“当前有效未退出、盈利最高”一致。热点线索同步限制为最多 5 条。

- [ ] **步骤 2：实现第一行三列**

按“今日盈亏、账户总盈亏、恐惧贪婪指数”顺序输出三张同规格指标卡。情绪卡展示 0-100 分值、五档标签、色带和风险页入口；无数据时展示明确空态。

- [ ] **步骤 3：实现第二行三列**

按“持仓信息、AI 高分推荐股、热点决策线索”顺序输出三个等宽、等标题高度面板。持仓与推荐列表最多 5 条，推荐行展示股票、状态、成本或参考价、现价与收益率。

- [ ] **步骤 4：实现全宽走势图与复盘行**

将“历史推荐组合走势”设为第三行横跨三列，将“复盘关键信息”设为第四行横跨三列，删除独立“风险关键信息”面板。

- [ ] **步骤 5：收敛响应式样式**

桌面 `grid-template-columns: repeat(3, minmax(0, 1fr))`；第一、二行主板块使用稳定最小高度；低于 1100px 时第二行可转两列，低于 760px 时全部单列，同时让全宽面板重置为单列跨度，避免内容溢出和重叠。

- [ ] **步骤 6：运行测试和构建**

运行：`cd web && npm test && npm run build`

预期：结构契约测试通过，`vue-tsc` 与 Vite 生产构建成功且无错误。
